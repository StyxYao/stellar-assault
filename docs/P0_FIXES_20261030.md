## 1. Run 来源隔离

### 问题

审计复现：

```text

__setScore(54321);

```

Stage Select 和 LAN 被无条件写入：

```text

```

### 修复

新增 Run 来源：

```text
campaign     完整战役
stageSelect  单关选择
lan          LAN 对局
```

实现：

```text
src/game/stage-flow.js
  var runSource
  resetRun(source)
  startGame() -> campaign
  startAtStage(i, source) -> stageSelect / lan

src/app/save.js
  recordRunEnd: 非 campaign 只更新 lastRunResult
  recordScoreSnapshot: 非 campaign 直接返回
  recordStageClear: 非 campaign 直接返回

src/app/run-rank.js
  runRankRecord(won, persist)
```

入口：

```text
Stage Select -> startAtStage(selectedStage, 'stageSelect')
LAN Host     -> startAtStage(..., 'lan')
```

效果：

- Stage Select 不再污染 campaign Top5 / wins / bestScore / unlockedStage
- LAN 不再污染 campaign
- lastRunResult 仍可用于结算显示

