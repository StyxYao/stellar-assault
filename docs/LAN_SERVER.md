# LAN Server Packaging

## Desktop / Electron

The Electron shell starts the dependency-free Node LAN server automatically:

```text
http://<LAN-IP>:8785
ws://<LAN-IP>:8786
```

The window loads from the LAN IP so invite links generated by the LAN panel point at a reachable address.

## Standalone Node

```bash
node tools/lan_server.mjs 8785 8786
```

or:

```bash
./tools/start_lan.command
```

Windows: `tools\start_lan.bat`.

Requires Node.js 18+; no `npm install`, no `websockets` package.

## Python fallback

The old `tools/lan_server.py` remains for compatibility, but requires `pip install websockets`.
