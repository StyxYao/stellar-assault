# Main Menu / Ship UI

## Main menu modes

Home is now a first-level mode choice:

```text
LOCAL SOLO   1 PLAYER
LOCAL CO-OP  2 PLAYERS
LAN CO-OP    HOST / JOIN
```

- LOCAL SOLO → loadout confirm, P2 controls hidden
- LOCAL CO-OP → loadout confirm with P2 ship/variant
- LAN CO-OP → LAN room panel

Desktop keys:

```text
1 = LOCAL SOLO
2 = LOCAL CO-OP
3 = LAN CO-OP
Tab = cycle mode highlight
Enter = open highlighted mode
```

## Ship select

- Ship page keeps the ship tutorial button.
- Choosing a ship opens the variant page.
- Variant page has:
  - `‹ SHIPS` back button
  - `×` close to menu
  - `TUTORIAL` button for the current ship
- Tutorial closes back to the variant page.
