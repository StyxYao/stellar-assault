# Main Menu / Ship UI

## Level 1 — mode only

The home screen contains only the mode choice:

```text
LOCAL SOLO   1 PLAYER
LOCAL CO-OP  2 PLAYERS
LAN CO-OP    HOST / JOIN
```

- No ship, variant or stage controls on this screen.
- Title wordmark is at the top.
- SA emblem is in the lower third.
- Desktop: `1 / 2 / 3`, `Tab`, `Enter`.

## Level 2 — Mission Setup

Selecting LOCAL SOLO or LOCAL CO-OP opens Mission Setup:

- P1 ship cycle
- P1 variant cycle
- Stage 1–5
- P2 ship/variant when local co-op is enabled
- co-op mode toggle
- START
- BACK TO MODES

Desktop:

```text
V = P1 ship
B = P1 variant
Arrow Left/Right or 1–5 = stage
P = co-op mode
J/K = P2 ship/variant
Enter = start
Esc = back
```

## Ship tutorial / variant page

The detailed ship page still exists as a secondary view:

- Ship page tutorial
- Variant page tutorial
- `‹ SHIPS` back button
- `TUTORIAL` button on the variant page
