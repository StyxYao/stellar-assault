# AEGIS Shield Fix

日期：2026-10-27

## 问题

- 破盾视觉反馈不够明显
- 护盾恢复后偶尔像被一击秒杀
- HP 掉血后没有可靠的无敌闪烁

## 原因

1. 护盾视觉半径很大，但子弹阻挡半径只有 `12px`，大部分看起来“打在护盾上”的子弹实际打到了 HP。
2. 护盾自动恢复只给 20 点，且没有恢复无敌帧；恢复瞬间继续吃伤害。
3. 破盾只闪 0.55 秒，没有持续 broken 状态提示。
4. HP 伤害路径没有强制清除 `noBlink`，也没有 hit flash。

## 修复

- 护盾阻挡半径改为随 Force 等级增长（`aegisShieldRadius()`）
- 吸收伤害后清除接触弹，并加 0.18 秒重入保护；同一颗弹不会每帧重复扣盾
- 直接伤害入口增加 `aegisAbsorbHit()`：Force attached 且 shield > 0 时优先消耗护盾，不扣 HP
- 破盾：
  - 1.2 秒无敌
  - 持续红色 broken 环 + 倒计时
  - 强制 HP 闪烁可用
- 自动恢复：
  - 回复 50% 护盾
  - 1.2 秒无敌
- 手动 RESTORE：满护盾 + 1.5 秒无敌
- HP 受伤：
  - `noBlink = false`
  - `hitFlashT = 0.22`
  - 1.0 秒无敌
- 机体下方新增护盾条
- 低护盾（≤12%）红色 `LOW SHIELD`，并有 `alarm` 音效
- HUD 低护盾/破盾变红

## 验收

- 护盾 attached 时直接伤害扣 shield，不扣 HP
- 破盾后 HP 逐点扣，1.0 秒无敌
- 连续两次命中第二次不扣 HP
- 恢复后 1.2 秒无敌
- 低护盾条/文字可见
- 破盾红色环和倒计时可见
- 单颗弹只扣一次护盾：60→52，弹体清除，HP 不变
- 恢复后单颗弹仍只扣一次：30→22，HP 不变
- 本地双人回归无 error
