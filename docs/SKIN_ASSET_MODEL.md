# 皮肤资产模型（简化版）

日期：2026-10-24  
决策：不做 body / ring / core 拆层；一套皮肤一张完整图。

---

## 1. 资产结构

### VECTOR

```text
vector_<skin>.png    80×80 完整机体图
```

不需要护盾层。

### AEGIS

```text
aegis_<skin>.png     80×80 完整机体图
aegis_shield.png     护盾/Force 叠加层
```

护盾层单独存在，但**不拆机体图**。

### PHANTOM

```text
phantom_<skin>.png   仅外观槽
```

机制后置，暂不接玩法。

---

## 2. AEGIS 状态表现

```text
ATTACHED   完整机体图 + 护盾层覆盖
DETACHED   完整机体图不动 + 护盾层前移
RETURNING  完整机体图不动 + 护盾层回旋
BROKEN     完整机体图不动 + 护盾层变暗/碎裂
REBUILDING 完整机体图不动 + 护盾层重组
```

关键：

- 不替换机体图
- 不删除机体图上的环
- Force 分离只移动护盾层
- 护盾层负责视觉与判定提示

---

## 3. 皮肤分配

按当前决定：

```text
VECTOR
- 星陨之翼（默认）
- 深渊之刃（红色，不改色）

AEGIS
- 虚空之矛（默认）
- 轨道守卫
- 虚空回响
- 时序巡游者（可作第 4 套/备用）

PHANTOM
- 量子猎手
- 幻影乌鸦
- 幻影蝶舞
```

说明：

- 虚空之矛从 VECTOR 组移到 AEGIS 默认。
- VECTOR 的第 3 套皮肤后续补，不在本次拆层。
- 深渊之刃保持原图红色，不做换色。
- 所有皮肤按原图颜色使用，不统一调色。

---

## 4. 护盾层

建议单张透明 PNG：

```text
aegis_shield.png
```

内容：

- 环形能量弧
- 中央能量核心
- 局部高光
- 透明背景

不包含：

- 船体
- 武器
- 文字
- 背景

运行时不拆船体，只控制护盾层：

- 位置
- 旋转
- 透明度
- 颜色叠加
- 破裂状态

---

## 5. 80×80 规则

- 机体图 80×80
- 透明背景
- 主体不超出 6px 安全边
- 小晶体最多保留 2 枚
- 红色/紫色皮肤必须有白色或青色玩家识别灯
- 护盾层可以是 96×96，绘制时叠加

---

## 6. 不再做的事

- 不拆 body / ring / core
- 不做 9 套独立拆件
- 不做机体图与 Force 的像素级分离
- 不做死亡后 Force 掉落的独立 sprite

先保证 R2 能完成，再考虑高精度拆层。
